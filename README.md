# Basement releases

Installers and server downloads for [Basement](https://getbasement.app), the media server for your own movies, shows, music and books.

Get the latest version from **[getbasement.app/download](https://getbasement.app/download/)** or from [Releases](https://github.com/mybsmt/basement-releases/releases).

Each release includes `SHA256SUMS` with a Sigstore signature so you can check what you downloaded. Install help: [getbasement.app/docs/install](https://getbasement.app/docs/install/).
